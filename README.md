# 📚 Student Notes Portal

A Django-based web application that allows students to upload, search, download, edit, and manage study notes securely.

## 🚀 Features

- User Registration
- User Login & Logout
- Upload PDF Notes
- Search Notes by Subject
- Download Notes
- Edit Note Details
- Delete Own Notes
- Secure Authentication
- Ownership-based Authorization

## 🛠 Tech Stack

- Python
- Django
- SQLite3
- Bootstrap 5
- HTML
- CSS
